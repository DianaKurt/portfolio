# Diana Suchkova — Portfolio

SPA-портфолио на React + Vite + TypeScript.

## Стек

- React 19, TypeScript, Vite
- GSAP (анимации + кастомный курсор)
- Тема: `prefers-color-scheme` + ручной переключатель

## Локально

```bash
npm install
npm run dev
```

## Деплой

### Vercel (превью / continuous)

1. Импортируйте репозиторий в Vercel
2. Framework preset: Vite
3. Build: `npm run build`, Output: `dist`

### GitHub Pages (`dianakurt.github.io`)

Репозиторий должен называться **`DianaKurt.github.io`** (user site), `base: '/'` в `vite.config.ts`.

```bash
npm run deploy
```

Или подключите Actions / Pages из ветки `gh-pages`.
